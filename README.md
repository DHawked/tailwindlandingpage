# Tailwind Landing Page

Basit bir açılış sayfası tasarımı için Tailwind CSS kullanılarak hazırlanmış minimal bir HTML sayfası.

## Özellikler

- **Responsive tasarım**: Mobil uyumlu, tablet ve masaüstü cihazlarda düzgün görüntülenir.
- **Modern görseller**: Tailwind CSS'in sunduğu utilities ile şık ve temiz bir görünüm.
- **Özelleştirilebilir içerik**: Metinler ve görseller kolayca değiştirilebilir.
- **Hızlı kurulum**: Sadece bir HTML dosyası ile çalışır.
